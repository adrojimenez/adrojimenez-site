# adrojimenez.com

Sitio estático (HTML, CSS y JS en un solo archivo). No necesita build.

## Publicar
1. Crear un repositorio en GitHub y subir todo el contenido de esta carpeta.
2. En Vercel: Add New > Project > importar el repositorio. Framework: Other. No hay comandos de build ni carpeta de salida.
3. En el proyecto de Vercel: Settings > Domains > agregar `adrojimenez.com` (y `www.adrojimenez.com`).
4. Vercel muestra los registros DNS exactos. Agregarlos donde se compró el dominio y esperar la verificación.

## Editar
- Proyectos: arreglo `PROJECTS` dentro de `index.html`.
- Perfil y CV: función `aboutHTML`.
- Foto: `images/adrian.jpg`. CV: `Adrian-Jimenez-CV.pdf`.
